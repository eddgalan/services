# Magento 2.4.7 - Entorno de Desarrollo

Esta branch está destinada exclusivamente al trabajo con el proyecto **Magento 2.4.7**.

Repositorio base utilizado:  
👉 https://github.com/eddgalan/Magento-2.4.7

## Objetivo

Mantener un entorno limpio, actualizado y aislado para desarrollar, probar y validar funcionalidades sobre Magento **versión 2.4.7**, siguiendo buenas prácticas de estructura y control de versiones.

## Contenido de esta branch

- Configuración del entorno para Magento 2.4.7  
- Archivos necesarios para la ejecución local con Docker / PHP / Composer (según corresponda)  
- Ajustes, módulos o pruebas específicos para esta versión  
- Cambios experimentales o en desarrollo antes de integrarlos en ramas principales  

## Requisitos del proyecto

- **Magento:** 2.4.7  
- **PHP:** versión compatible (8.2 recomendado)  
- **Composer:** 2.x  
- **MySQL / MariaDB:** según configuración del proyecto  
- **ElasticSearch u OpenSearch** (dependiendo del stack definido)

## Notas

- Esta branch no debe mezclarse con otras versiones del proyecto para evitar incompatibilidades.
- Si se agregan módulos o configuraciones personalizadas, documentarlos en este archivo o en la carpeta correspondiente.
- Para cualquier duda o actualización del flujo de trabajo, consultar el repositorio principal.
